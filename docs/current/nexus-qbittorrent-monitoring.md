# Nexus qBittorrent monitoring

As verified November 13, 2026, the existing Nexus `homelab-telemetry.service` samples qBittorrent's read-only Kong transfer and torrent endpoints with a dedicated `media-read` JWT. The gateway still has 69 routes/services and its four original consumers, plus `qbittorrent-metrics`. Secret source: root-only `/etc/nexus/secrets/monitoring/qbittorrent-metrics/jwt.json`; the same protected directory holds the immediate pre-deploy Kong recovery file. Original and staged Kong configuration and credential also have verified encrypted GitHub recovery on private `iragonforce/backup` branch `qbittorrent-metrics-kong-2026-11-12`, using Bitwarden item `API_KONG_BACKUP_GPG_PASSPHRASE_V1`.

The Nexus-only telemetry implementation is `hosts/nexus/files/usr/local/libexec/telemetry.py`, deployed at `/usr/local/libexec/homelab-telemetry.py`. Every ~60 monotonic seconds it publishes `qbittorrent.prom` into the existing Node Exporter textfile directory. It does not modify `homelab-telemetry.prom`; failure only publishes `qbittorrent_scrape_success 0` and retains the last successful timestamp. Transfer-byte `_total` metrics reflect the qBittorrent **session** and reset when the daemon's session resets, not lifetime totals. Torrent labels are fixed categories: downloading, seeding (including queued/stalled), paused, error, other. No per-torrent labels or identifiers are published. The metric family appears in Prometheus job `node-exporter-nexus`.

Grafana's file provider loads `nexus-qbittorrent-vpn.json` (UID `nexus-qbittorrent-vpn`, 15 panels). The existing `nexus-docker.json` (UID `nexus-docker-containers`, 14 panels) excludes shared namespace and host-network duplicates from container network views, and the new dashboard shows Gluetun `tun0` separately from qBittorrent's application transfer rates. PromQL queries returned live series and both resources loaded in Grafana's unified-storage `resource` table. Browser rendering remains unverified behind Grafana login (unauthenticated API returns 401).

Source, checks, backup commits, exact hashes, limitations and targeted rollback: `docs/changes/2026-11-13-nexus-qbittorrent-monitoring.md`. The private `iragonforce/backup` branch `qbittorrent-monitoring-2026-11-13` holds original telemetry/dashboard source; application state and Bitwarden are not backed up by that branch.
